# Create Exercise Skill

Use this workflow to generate practice exercises in `05_Practice/`:

1. **Levels of Mastery**:
   - Level 1: Recall & Verification
   - Level 2: Direct Formula Application
   - Level 3: Multi-Step Analytical Problem
   - Level 4: Business Edge Cases & Error Handling
   - Level 5: Capstone Connection
2. **Hidden Solutions**: Put detailed step-by-step solutions in collapsible callouts (`> [!tip]- Click to Expand Solution`) or separate solution files in `05_Practice/Solutions/`.
3. **Dataset Linking**: Explicitly link to files in `09_Source_Materials/`.
