# Create Concept Note Skill

Use this workflow to generate an atomic concept note in `03_Concepts/`:

1. **Atomic Focus**: Focus strictly on one reusable concept (e.g. `Structured References`, `Star Schema`, `XLOOKUP`).
2. **Follow 10 Questions**:
   1. What is it?
   2. Why is it used?
   3. How does it work?
   4. Syntax & Structure
   5. Practical Example
   6. Common Mistakes
   7. When to use
   8. When NOT to use
   9. Real-world analytics use case
   10. Related concepts
3. **Mermaid Flowchart**: Include at least one informative Mermaid flowchart illustrating the mental model.
4. **Bidirectional Links**: Link to related lessons and practice exercises.
