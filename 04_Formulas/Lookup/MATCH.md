# MATCH Function
> [!abstract] Purpose
> Returns the relative numerical position of an item in a 1D array matching a specified lookup value.

## Syntax
```excel
=MATCH(lookup_value, lookup_array, [match_type])
```
*Note: Always use `match_type = 0` for exact matches in analytics.*
