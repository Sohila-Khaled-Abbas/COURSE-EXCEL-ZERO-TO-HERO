# NETWORKDAYS Function
> [!abstract] Purpose
> Returns the number of whole working business days between two dates, automatically excluding weekends and optional user-specified holidays.

## Syntax
```excel
=NETWORKDAYS(start_date, end_date, [holidays])
```
