# TEXTJOIN Function
> [!abstract] Purpose
> Concatenates a list or range of text strings using a specified delimiter, with an option to ignore empty cells.

## Syntax
```excel
=TEXTJOIN(delimiter, ignore_empty, text1, [text2], ...)
```
