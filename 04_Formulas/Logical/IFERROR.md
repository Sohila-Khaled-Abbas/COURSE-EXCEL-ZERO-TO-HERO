# IFERROR Function
> [!abstract] Purpose
> Traps and intercepts calculation errors (`#N/A`, `#VALUE!`, `#DIV/0!`, `#REF!`), returning a designated fallback value instead.

## Syntax
```excel
=IFERROR(value, value_if_error)
```
