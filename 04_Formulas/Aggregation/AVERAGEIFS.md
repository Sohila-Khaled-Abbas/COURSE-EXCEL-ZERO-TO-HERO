# AVERAGEIFS Function
> [!abstract] Purpose
> Calculates the arithmetic mean of all cells in a range that meet multiple criteria.

## Syntax
```excel
=AVERAGEIFS(average_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)
```
