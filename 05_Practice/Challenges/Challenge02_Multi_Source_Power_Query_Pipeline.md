# Capstone ETL Challenge: Automated Currency Conversion Pipeline

> [!abstract] The Challenge
> Ingest international sales transactions denominated in EUR, GBP, and JPY. Connect Power Query to the live exchange rates REST API (from `Module 7/2-Importing Data/M language to Deal with API.txt`), parse the JSON response, join the real-time rates against the sales transactions, and output all revenues normalized to USD.
