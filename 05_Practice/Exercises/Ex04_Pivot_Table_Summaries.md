# Exercise 4: Multi-Dimensional Pivot Table Summaries

> [!abstract] Objective
> Construct executive summary tables, group dates into quarterly hierarchies, and calculate percentage distributions using "Show Values As".

## Tasks & Challenges
- [ ] **Level 1**: Build a Pivot Table showing Total Sales by `Region` (Rows) and `Product Category` (Columns).
- [ ] **Level 2**: Group transactional dates into `Years` and `Quarters`.
- [ ] **Level 3**: Add a second instance of `Sales` to the Values area and configure it to display as `% of Column Total`.
- [ ] **Level 4**: Insert a Timeline control and verify multi-period slicing.
