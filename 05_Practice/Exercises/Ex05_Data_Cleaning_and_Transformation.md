# Exercise 5: Data Quality Audit & Forensic Cleaning

> [!abstract] Objective
> Perform a comprehensive data quality audit across the six dimensions, isolate blank records using Go To Special, and standardize corrupted datatypes.

## Tasks & Challenges
- [ ] **Level 1 (Completeness Audit)**: Calculate the percentage of missing values across all columns.
- [ ] **Level 2 (Blank Imputation)**: Using `Go To Special > Blanks`, impute missing numerical quantities with `0`.
- [ ] **Level 3 (Text Standardization)**: Use Text to Columns to separate `"City, State Zip"` into 3 independent attributes.
- [ ] **Level 4 (Validation Check)**: Identify invalid records where transaction date is in the future.
