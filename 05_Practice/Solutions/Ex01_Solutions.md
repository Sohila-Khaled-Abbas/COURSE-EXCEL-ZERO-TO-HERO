# Solutions: Exercise 1 (Data Management & Formatting)

### Task 1: Accounting Format
- Select Revenue column -> `Ctrl + 1` -> Accounting -> Symbol `$`, 2 decimal places.

### Task 2: Custom Phone Number Formatting
- Select Phone column -> `Ctrl + 1` -> Custom -> Type: `(###) ###-####`.

### Task 3: Data Validation Dropdown
- Select Region cells -> `Alt + A + V + V` -> Allow: **List** -> Source: `North, South, East, West`. Error alert: Style = **Stop**.

### Task 4: Multi-Level Sort
- Data > Sort -> Level 1: Region (A to Z) -> Add Level -> Level 2: Revenue (Largest to Smallest).
