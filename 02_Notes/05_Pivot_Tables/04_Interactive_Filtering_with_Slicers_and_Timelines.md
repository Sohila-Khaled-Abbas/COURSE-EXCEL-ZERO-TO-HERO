# Lesson 5.4: Slicers, Timelines & Report Connections

> [!abstract] Learning Objective
> Connect interactive visual filter controls (Slicers & Timelines) across multiple independent Pivot Tables using Report Connections to create unified dashboard interactivity.

> 🎥 **Video Chapter**: [Chapter 5 – Pivot Tables (2:58:28)](https://www.youtube.com/watch?v=uv1bxe2gdnU&t=10708s)

## Step-by-Step Report Connections
1. Insert a Slicer on any Pivot Table (**PivotTable Analyze > Insert Slicer**).
2. Right-click the Slicer title -> select **Report Connections...**.
3. Check the boxes for ALL Pivot Tables across the workbook that should respond to this filter.
4. Now, selecting an Agent or Topic filters the KPI cards, distribution charts, and summary tables simultaneously!
