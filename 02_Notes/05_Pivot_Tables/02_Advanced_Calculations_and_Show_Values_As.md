# Lesson 5.2: Advanced Calculations & Show Values As

> [!abstract] Learning Objective
> Transform raw numerical summaries into percentage shares, running totals, rank orderings, and variance comparisons using the "Show Values As" calculation engine.

> 🎥 **Video Chapter**: [Chapter 5 – Pivot Tables (2:58:28)](https://www.youtube.com/watch?v=uv1bxe2gdnU&t=10708s)

## High-Yield Show Values As Options
- **% of Grand Total**: Displays the proportion of each row/column relative to the entire dataset (e.g. % of total calls by topic).
- **% of Column / Row Total**: Useful in cross-tabulations (e.g. % of answered calls that were resolved vs unresolved).
- **Running Total In**: Cumulative running sums over chronological periods.
- **Difference From / % Difference From**: Month-over-month or period-over-period variance against a baseline.
