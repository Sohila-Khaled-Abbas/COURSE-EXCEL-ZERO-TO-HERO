# Lesson 4.3: Table Features, Total Rows & Slicer Integration

> [!abstract] Learning Objective
> Enable Total Rows, build calculated summaries, and integrate visual Slicers directly onto Excel Tables for interactive filtering.

> 🎥 **Video Chapter**: [Chapter 4 – Excel Tables (2:35:55)](https://www.youtube.com/watch?v=uv1bxe2gdnU&t=9355s)

## Core Features
1. **Total Row (`Ctrl + Shift + T`)**:
   - Appears at the bottom of the table without disrupting row expansion.
   - Provides instant dropdown aggregations (`SUBTOTAL` functions that automatically respect filters).
2. **Table Slicers**:
   - Click inside Table -> **Table Design > Insert Slicer**.
   - Select categorical columns (e.g. `Topic`, `Answered (Y/N)`).
   - Provides a clean, modern UI for filtering without clunky header dropdowns.
