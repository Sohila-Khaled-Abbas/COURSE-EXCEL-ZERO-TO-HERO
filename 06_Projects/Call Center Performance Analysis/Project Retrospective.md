# 9. Project Retrospective & Technical Competencies

## Technical Competencies Demonstrated
1. **Forensic Data Quality Auditing**: Correctly diagnosed that 946 null values were valid missing data resulting from abandoned calls rather than data loss.
2. **Advanced Excel Modeling**: Utilized formal Excel Tables (`ListObjects`), calculated columns, and multi-condition `COUNTIFS` aggregations.
3. **Power Pivot & DAX Integration**: Formulated dynamic measures utilizing `DIVIDE` and `CALCULATE` to prevent calculation errors.
4. **Interactive Dashboard Engineering**: Synchronized multiple Pivot Tables through Slicer Report Connections and implemented a VBA filter reset button.
5. **Business Storytelling**: Translated statistical observations into actionable staffing, technology, and process recommendations.
