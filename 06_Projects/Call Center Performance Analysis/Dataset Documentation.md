# 2. Dataset Documentation

## Source & Timeframe
- **Source File**: `09_Source_Materials/Module 9/13/PWC Dataset.xlsx`
- **Sheet Name**: `Source Data `
- **Timeframe**: January 1, 2021 through March 31, 2021 (Q1 2021, exactly 90 operational days).
- **Row Count**: Exactly 5,000 unique call interaction rows.
- **Column Count**: 10 primary analytical attributes (after purging blank trailing columns).

## Granularity
Each row represents a single inbound telephone call transaction logged by the Automated Call Distribution (ACD) telephony switch.
