## Reporting a Vulnerability

We take the security and integrity of our repository and educational materials seriously.

If you discover a security vulnerability or sensitive information exposure (such as accidental credentials, private API keys, or malicious files):

1. **Do not create a public GitHub Issue.**
2. Send a detailed report via email to **[sohila.k.data@gmail.com](mailto:sohila.k.data@gmail.com)**.
3. Include:
   - Description of the vulnerability.
   - Specific file paths and commit hashes.
   - Potential impact.
   - Any suggested remediation steps.

### Response Timeline
- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Remediation & Patch**: Promptly upon verification.

Thank you for responsibly disclosing security issues to protect our learning community!
