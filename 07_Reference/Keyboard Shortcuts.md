# ⌨️ Power-User Keyboard Shortcuts

## 1. High-Frequency General Shortcuts
- `Ctrl + T` or `Ctrl + L`: Convert selection to official Excel Table (`ListObject`).
- `Ctrl + Shift + T`: Toggle Excel Table Total Row on/off.
- `F4`: Toggle reference lock (`A1` -> `$A$1` -> `A$1` -> `$A1`) OR repeat last command.
- `F2`: Enter cell edit mode.
- `Ctrl + 1`: Open Format Cells dialog box.
- `Ctrl + Shift + L`: Toggle AutoFilter dropdowns on/off.
- `Ctrl + E`: Trigger Flash Fill pattern detection.
- `Alt + =`: Instant AutoSum on selected column/row.
- `Alt + F5`: Refresh active Pivot Table or Power Query connection.
- `Ctrl + Alt + F5`: Refresh All Pivot Tables and queries in the entire workbook.

---

## 2. Navigation & Selection
- `Ctrl + Arrow Keys`: Jump to edge of data block.
- `Ctrl + Shift + Arrow Keys`: Highlight selection to edge of data block.
- `Ctrl + Space`: Select entire column. *(Inside an Excel Table: press once to select data body; press twice to include header and total)*.
- `Shift + Space`: Select entire row. *(Inside an Excel Table: selects the table row)*.
- `Ctrl + A`: Select all. *(Inside an Excel Table: press once to select data body; press twice to select entire table container)*.
- `Tab`: In the bottom-right cell of an Excel Table, instantly appends a new table row and auto-propagates calculated column formulas.
- `Ctrl + Home`: Return to cell `A1`.
- `Ctrl + End`: Jump to the bottom-rightmost used cell.

---

## 3. Row & Column Editing
- `Ctrl + Plus (+)`: Insert new row(s) or column(s).
- `Ctrl + Minus (-)`: Delete selected row(s) or column(s).
- `Alt + H + O + I`: Auto-fit column widths.
